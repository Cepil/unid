# Uni-DTHON 팀 코드

현재 최고 결과는 **Hybrid v2 / Public Macro F1 0.9003493296**입니다. 코드·학습/추론 방법·가중치 전달 안내는 [팀 전달 문서](TEAM_HANDOFF.md)에 정리했습니다.

| 모델 | Train GroupKFold 평균 | 제공 Validation | Public |
| --- | --- | --- | --- |
| 배포 베이스라인 | 약 0.806 | 약 0.677 | 0.8010471797 |
| Fusion v1 | 0.815681 | 0.778443 | 0.8504558014 |
| Hybrid v2 | 0.862176 | 0.727172 | **0.9003493296** |

Hybrid v2는 이미지·센서 MLP 3개 시드의 평균과, 이미지·센서 트리 모델의 확률을 50:50으로 결합합니다. 이미지 인코더는 고정된 ResNet-18입니다. 현재 관측만 사용하며 학습된 전처리를 그대로 적용합니다.

- [현재 후보 코드](hybrid_v2/): 추론·학습·검증 코드, 가중치 패키징 도구.
- [실험 재현 코드](experiments/fusion_v1/): v1과 같은 fold에서 후보를 비교한 CV/분석 코드.
- 대회 데이터, 예측 CSV, 로그, 캐시, 인증정보는 레포에 포함하지 않습니다.
- 가중치 바이너리는 레포에 포함하지 않으며 사용자가 팀 카톡으로 `hybrid_v2_weights.tar.gz`를 전달합니다. 체크섬은 `hybrid_v2/WEIGHTS_MANIFEST.json`, 설치법은 TEAM_HANDOFF.md를 따릅니다.

Public 상승은 Private 성능을 보장하지 않습니다. 최종 제출 파일 선택 상태도 DAKER에서 별도로 확인해야 합니다.
